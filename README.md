# 🎓 Study Buddy

**Study Buddy** is a comprehensive student performance tracking and AI-powered learning platform. It empowers students to monitor their contest scores, practice coding in an integrated Java environment, and improve their skills through AI-generated quizzes and personalized analytics.

---

## 🚀 Core Features

### 👨‍🎓 Student Dashboard
- **Performance Overview**: Real-time tracking of normalized Vedam scores across various subjects.
- **Eligibility Tracking**: Automatically calculates eligibility for Innovation and Placement milestones.
- **Subject Catalog**: Deep dives into contest breakdowns for Maths, Java, and Web development.

### 💻 Java Contest Editor
- **Integrated Environment**: A full-featured Monaco-based code editor for Java.
- **Templates & Testing**: Provides boilerplate code for contest questions and allows for submission of solutions.
- **AI Evaluation**: Solutions are automatically evaluated by AI to provide detailed performance reports.

### 🤖 AI-Powered Learning
- **Dynamic Quizzes**: Generate personalized quizzes for Maths, Java, or Web development based on specific topics and difficulty levels.
- **Practice Tasks**: AI-generated practice questions derived from contest performance and historical gaps.
- **Historical Analysis**: Aggregated performance reports and trend analysis generated by AI.

### 🛠️ Admin Panel
- **Contest Management**: Tools to upload contest data and manage student submissions via JSON.
- **Student Registration**: Manage student records and publish scores.
- **Performance Monitoring**: Overview of all student progress and eligibility statuses.

---

## 💻 Tech Stack

- **Frontend**: React 18, Vite
- **Styling**: Vanilla CSS (Modern, Responsive Design)
- **Backend/Database**: Firebase (Authentication, Firestore)
- **Code Editor**: Monaco Editor
- **AI Integration**: AI-driven evaluation and content generation

## 🛠️ Setup & Installation

### Prerequisites
- Node.js (version specified in `.nvmrc`)
- Firebase Account

### Installation
1.  **Clone the repository**:
    ```bash
    git clone [repository-url]
    cd Study_buddy
    ```
2.  **Install dependencies**:
    ```bash
    npm install
    ```
3.  **Environment Variables**:
    Create a `.env` file in the root directory and add your Firebase configurations (see `.env.example` for reference).
    ```env
    VITE_FIREBASE_API_KEY=your_api_key
    VITE_FIREBASE_AUTH_DOMAIN=your_auth_domain
    VITE_FIREBASE_PROJECT_ID=your_project_id
    VITE_ALLOWED_EMAIL_DOMAIN=your_domain.com
    ```
4.  **Run Development Server**:
    ```bash
    npm run dev
    ```
